# ARMusic 参赛网页版

[打开 Qoder Sites 试玩页](https://armusic-posters-edzpguldzve.qoder.website/) · [查看素材来源](交接与素材来源.md)

打开 [site/index.html](site/index.html) 即可本地试玩。发布只需要 `site/` 目录，无需安装依赖和构建。两部作品和三个试听版本都随网页提供。

## 试玩流程

1. 点《夜行支线》，在作品详情里查看曲目，并试听《末班车经过山谷》。
2. 播放到约第 8 秒时，在播放器里切换毡音键盘和高八度钟琴，比较同一段旋律。暂停时切换也会保留进度和暂停状态。
3. 点《退潮图志》，新曲从头播放。同一时间只有一个播放器。

首次使用提示关闭后会在当前浏览器记住，也可以通过页面顶部的“使用提示”重新打开。

## 源码和提交材料

- [catalog.js](site/catalog.js) 是网页使用的作品、曲目和编曲版本数据。文件路径以 `site/` 为根。新增作品、曲目和版本时按现有结构填写。
- [home.js](site/home.js) 负责海报墙与首次使用提示。[player.js](site/player.js) 负责作品详情、曲目选择和试听，在浏览器中独立运行。
- [作品帖初稿](作品帖初稿.md) 供天池提交使用。[Qoder 开发记录](Qoder开发记录.txt) 和[验收截图](验收截图) 可作为开发和演示材料。
