## 接入正式作品页和播放器

1. 首页的海报点击入口是 [home.js](site/home.js) 中的 `openWork(work, card)`。把 `work.id` 传给正式作品页，接管当前页面的试听区和音频播放，避免两个播放器同时出声。
2. 根据[曲库样例](曲库样例.json)映射作品、曲目和版本。页面实际读取 [catalog.js](site/catalog.js)。列车海报对应作品 `night-rail`，曲目 `last-train` 下有 `felt` 和 `bells` 两个版本。封面和音频的相对路径以 [site](site) 为根。
3. 联调时检查三种操作：播放途中切版本应从原位置继续；暂停后切版本应停在原位置；换另一部作品应播放新曲目。首次提示关闭后刷新应保持收起，点“使用提示”可重开。
4. 正式播放器接好后，把分支或提交链接发回给首页负责人，由首页负责人更新现有 Qoder Sites 地址。两人再用电脑和手机真机各走一次完整流程。当前线上版已通过未登录桌面浏览器和手机尺寸模拟验收。
