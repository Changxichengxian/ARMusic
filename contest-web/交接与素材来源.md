# ARMusic 首页交接

双击 site/index.html 直接试玩。整个 site 目录是可部署的静态站点，入口为根目录的 index.html，无需构建、外部字体、网络音源或登录。站点只需这一目录的内容。

## 素材来源

## 接入正式播放器

曲库样例.json 是当前页面数据的 JSON 快照，供队友映射到正式曲库格式。site/catalog.js 为页面读取的数据源，三级结构依次是作品、曲目和版本。同曲的两个版本共享 track.id，独立的 version.id 对应各自 src。cover 和 src 都以站点入口为相对路径。所有音频都是 22.05 kHz、单声道、16 位 PCM WAV。

首页按钮在 site/home.js 中调用 openWork(work, card)。队友可在此接入正式作品页并传入 work.id。当前试听区作为独立原型，让首页、素材和同曲对比可在联调前验收。若正式曲库更换字段名，只需对照样例映射。首次提示使用本地存储按浏览器记忆，页首“使用提示”可随时重新打开。
