# ARMusic：记得那部作品，就能找到它的歌

**赛道**　LifeHack 生活娱乐  
**公开试玩**　https://armusic-posters-edzpguldzve.qoder.website/  
**参赛成员**　〔两人昵称、各自 Qoder 账号与一句本人简介〕

有时我记得最后一班列车穿过山谷的画面，却想不起那段音乐叫什么。即便找到了曲名，也想再听一遍另一种编曲，弄明白当初打动我的是旋律，还是声音本身。ARMusic 把找歌的入口放在作品海报上。

这个网页版为喜欢动画、游戏和影视原声的人准备了两部虚构作品。《夜行支线》里，先听毡音键盘演奏的《末班车经过山谷》，再切到高八度的钟琴。同一段旋律走到哪里，切换后就从哪里接着听。《退潮图志》则用一段簧管配乐，给一座虚构的浅湾配上声音。两幅海报与三段试听都为本次演示重新制作。

## 怎么玩

1. 打开试玩链接，点《夜行支线》的列车海报。
2. 听几秒毡音键盘，然后点“高八度钟琴”，比较同一小节的音色。
3. 暂停或拖动进度，再点《退潮图志》，听另一部作品的配乐。

## 两个人怎样完成

分工上，一位队员负责作品详情、正式播放器、同曲切换和最终提交；另一位负责海报墙、首次提示、示例素材、作品帖初稿与站点发布。

首页和配乐从本地 Codex 原型起步。我们用 Qoder 调整了首次使用体验：关闭提示后，键盘焦点直接落到第一张海报，按回车就能试听。重新打开提示时，按钮也会把展开状态告知屏幕阅读器。我们随后用 Qoder Sites 发布了海报墙。在两个未登录的浏览器会话中，以桌面和手机尺寸完成了试听和同曲切换。〔提交前由队友补入正式播放器的 Qoder 开发过程和对应截图。〕

既有 ARMusic 包含 Android 和 Windows 播放器，安卓版源自 LMusic 1.5.4。此次首页原型单独实现，海报、音乐和页面均随原型交付。〔队友合入后按实际代码来源及官方答复更新本段。〕
