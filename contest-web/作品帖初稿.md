# ARMusic 记得那部作品就能找到它的歌

**赛道**　LifeHack 生活娱乐

**公开试玩**　待填最终 Qoder CN Sites 链接

**参赛成员**　待补两人的参赛昵称、一句自我介绍，以及作品使用的 Qoder 账号

有时我记得最后一班列车穿过山谷的画面，却想不起那段音乐叫什么。即便找到了曲名，也想再听一遍另一种编曲，弄明白当初打动我的是旋律，还是声音本身。ARMusic 把找歌的入口放在作品海报上。

这个网页为喜欢动画、游戏和影视原声的人准备了两部虚构作品。《夜行支线》里，先听毡音键盘演奏的《末班车经过山谷》，再切到高八度钟琴。你可以在同一段旋律的位置比较音色，也可以暂停后切换。《退潮图志》则用一段簧管配乐，给一座虚构的浅湾配上声音。两幅海报和三段试听都为这次演示制作。

## 怎么玩

1. 打开试玩链接，点《夜行支线》的列车海报，在作品详情里选中《末班车经过山谷》。
2. 播放到约第 8 秒，点“高八度钟琴”。播放器会从相近位置接上，并显示恢复的时间。
3. 暂停后切回“毡音键盘”，试听仍停在原位置。点《退潮图志》即可从头听另一部作品的配乐。

## 两个人怎样完成

一人负责首页海报墙、首次使用提示、示例素材和介绍初稿，另一人负责作品详情、曲目列表、播放与切换、验收和最终提交。

海报墙从本地 Codex 原型起步。我们用 Qoder 调整了首次使用体验，关闭提示后键盘焦点会落到第一张海报，按回车即可试听。播放器联调时，Qoder 帮我们在同曲切换真正定位后显示版本名和时间。我们随后用 Qoder CN 改进失败重试，断开的音频请求恢复后可以重新从原进度听。Edge 桌面和手机尺寸均验证了切换、暂停和重新播放。

既有 ARMUSIC 包含 Android 和 Windows 播放器，安卓版基于开源项目 LMusic 1.5.4。本次提交的网页版在赛期内单独开发，使用这次制作的海报、配乐和独立的网页播放器。素材生成方式和开发会话记录随代码附上。
